# Murugan Marine & Offshore Solutions LLC

A modern, responsive, high-performance web platform built for **Murugan Marine & Offshore Solutions LLC** (UAE & Oman). This platform synthesizes core operations across heavy marine rigging, CNC metal fabrication, shipyard afloat engineering, and industrial chemical solutions.

Inspired by industry leaders across the GCC:
- **Roma Enterprises Reference**: Marine Rigging, Lifting Hardware, Galvanized Short Link DIN 766 & G80 Chains, Wire Ropes, Bow Shackles.
- **Safari Metal Reference**: 15kW CNC Fiber Laser Cutting, 400-Ton Press Brake Sheet Bending, Marine SS316L, Custom Skid Units.
- **MFE Oman Reference**: Afloat Ship Repairs, ASME B31.3 Pipe Spool Pre-fabrication, Class Coded 6G Welding (DNV, ABS, Lloyd's).
- **Oasis Chemical Reference**: HD-90 Solvent Degreasers, SafeScale-Eco Inhibited Descalers, Boiler Water Treatments, IMO Oil Spill Dispersants.

---

## 🚀 Key Features

- **Interactive Product Catalog**: Real-time keyword & category search with technical specification modals.
- **RFQ (Request for Quote) Cart**: Add items, set custom configurations, select destination ports, and generate proforma reference numbers with print support.
- **Engineering Calculators Suite**:
  - *Chain & Rigging WLL Calculator* (EN 818-4 & ASME B30.9 formulas).
  - *Marine Chemical CIP Dosage Estimator* for plate coolers, boilers, and evaporators.
  - *Safari Metal Sheet Mass & Laser Cutting Estimator*.
- **GCC Port Mobilization Network**: Live dispatch response times and contact directory for Sharjah, Dubai, Sohar, Muscat, Salalah, and Fujairah.
- **Project Case Studies & Class Society Approvals**: Verified compliance with DNV GL, Lloyd's Register, ABS, Bureau Veritas, ISO 9001:2015, ASME, and IMO/MARPOL.

---

## 🛠️ Tech Stack

- **Frontend**: HTML5, Modern ES6+ JavaScript, Tailwind CSS, Google Fonts (Oswald & Inter)
- **Icons**: Lucide Icons
- **Modular Components (React/Vite)**: Ready-to-use React components located in `src/`
- **Server / Launcher**: Python 3 `http.server` & Windows batch launcher (`start.bat`)

---

## 🚦 Getting Started

### 1. Direct Browser Launch
Simply double-click `index.html` to run in any modern web browser.

### 2. Local Development Server
Double-click `start.bat` or run:
```bash
python -m http.server 8000
```
Then navigate to `http://localhost:8000` in your browser.
